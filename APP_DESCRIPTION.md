# SREdesigns (Portfolio)

**SREdesigns** is a **Premium Digital Portfolio** showcasing high-end full-stack architecture and design. It serves as the central hub for the developer's professional identity, featuring a diverse range of projects from web apps to AI experiments.

### 🎯 Key Product Essence

The site is built to impress. It uses **rich animations, glassmorphism, and dynamic typography** to communicate a "Full-Stack Architect" brand. It's not just a resume; it's a demonstration of frontend mastery, featuring direct integrations with GitHub data and AI art galleries.

### 🛠️ Technical Stack

* **Frontend**: React (Vite) with `framer-motion` for complex orchestrations.
* **Styling**: Tailwind CSS with custom utility classes for "glass" effects and gradients.
* **Assets**: Uses `lucide-react` for consistent iconography.
* **Data Sources**: Static data files (`/data/repos`, `/data/midjourney`) powering dynamic project grids.

### ✨ Core Features

* **Dynamic Hero Section**: Atmospheric entry with particle effects and smooth fade-in animations.
* **Project Showcase**: A filtered grid of work (Web Apps, Automation, AI) with "holographic" card effects.
* **Media Gallery**:
  * **Midjourney Art**: A curated section displaying AI-generated artwork.
  * **Video Hub**: Integration for showcasing demo reels or tutorials.
* **Interactive UI**: Smooth scrolling, hover states, and a premium "dark mode" aesthetic throughout.
* **Contact & Socials**: Polished footer and navigation for professional outreach.

### 📂 Directory Insights

* `/src/App.jsx`: The single-page application structure.
* `/src/data`: Contains the content repositories for projects and art, allowing easy updates without code changes.
* `/src/components/ui`: Reusable high-fidelity UI components (inferred from usage).
